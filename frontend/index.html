About SiliconRoute

Local-first heterogeneous AI load balancer for laptop processors.

What It Is

SiliconRoute is a self-learning load balancer that measures real inference latency, fits physical hardware performance models, and routes each neural network execution to the optimal silicon (CPU, integrated GPU, discrete GPU, or NPU).

Limitations

1. FP32 Precision: Profiled synthetic models currently use float32 precision.

2. DirectML execution provider on Windows; CUDA/TensorRT not evaluated.

3. Telemetry: Unprivileged Windows APIs do not expose CPU package power or AMD iGPU package power.

4. Reference Hardware: Published benchmarks evaluated on AMD Ryzen 9 8940HX, AMD Radeon 610M, and NVIDIA GeForce RTX 5070 Laptop GPU.
