    About SiliconRoute

    Mission, system architecture, honest technical limitations, and license

    Mission

    SiliconRoute is a local-first, self-learning AI load balancer for laptops. It measures how neural network models execute on every physical chip (CPU, iGPU, dGPU), stores every run in SQLite, fits empirical hardware performance models, and routes tasks to optimize for speed, battery life, or thermal limits.

    Honest Limitations

    • FP32 precision only: Single-precision float32 models; FP16 and INT8 tensor core acceleration are planned.
    • DirectML on Windows: GPU acceleration uses Microsoft DirectML; native CUDA or TensorRT execution providers are not used.
    • Synthetic model topologies: Benchmarks currently evaluate parameterized MLP, Convolution, and Attention architectures.
    • Evaluated on profiled configurations: Unseen topologies rely on fitted hardware models with an average LOO MAPE of ~.
    • Session variability: The discrete GPU exhibits cross-session timing spread up to under identical configurations.
    • Single laptop: Reference system: AMD Ryzen 9 8940HX, AMD Radeon 610M, NVIDIA GeForce RTX 5070 Laptop GPU.

    Licence

    Released under the open-source MIT License. Zero telemetry upload, zero external database servers.
