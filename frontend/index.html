Physics & algorithmic notes

DirectML Winograd convolution hypothesis: conv-96 exhibits a marked latency increase on RTX compared to conv-64, despite smooth scaling on CPU and Radeon 610M. This points to an algorithmic selection boundary in DirectML's GEMM/Winograd conv implementation on NVIDIA Ada/Blackwell architecture.

    Hardware identity audit

    During early benchmarking, Windows DirectX occasionally inverted adapter indexing between the AMD Radeon 610M integrated GPU and NVIDIA RTX 5070 discrete GPU. A strict identity audit based on DXGI LUID and NVML clock checks detected and flagged suspect runs. All flagged runs were completely excluded from model fits and evaluation.

    About SiliconRoute

    Mission, system architecture, honest limitations, and development methodology.

    Mission

    SiliconRoute is a local-first, self-learning AI load balancer for laptops. It measures how neural network models execute on every physical chip (CPU, iGPU, dGPU), stores every run in SQLite, fits empirical hardware performance models, and routes tasks to optimize for speed, battery life, or thermal limits.

    Limitations

    SiliconRoute is committed to complete transparency regarding its current technical scope:

    • FP32 precision only: All profiled models execute in single-precision float32. FP16 and INT8 tensor core acceleration are planned for future versions.
    • DirectML on Windows: GPU acceleration uses Microsoft DirectML; native CUDA or TensorRT execution providers are not used.
    • Synthetic model topologies: Benchmarks currently evaluate parameterized MLP, Convolution, and Attention architectures. Real-world LLM and vision topologies are planned.
    • Evaluated on profiled configurations: The published evaluation tested previously profiled models. Unseen topologies rely on fitted hardware models with an average LOO MAPE of ~.
    • Session variability: The discrete GPU exhibits cross-session timing spread up to under identical configurations.
    • Single laptop: All published data originates from a single reference laptop (AMD Ryzen 9 8940HX, AMD Radeon 610M, NVIDIA GeForce RTX 5070 Laptop GPU).

    How this was built

    Authored by Tanmay, who established the measurement methodology, router logic, and strict integrity rules. Code implementation and refactoring were executed collaboratively with AI coding agents (Google Antigravity and Anthropic Claude).

    Under SiliconRoute's integrity protocol, no benchmark figures are ever generated or estimated by LLMs. Every published number is verified directly against the frozen SQLite database by automated test suites.

    Architecture

    Built on Windows 11 with Python 3.12, FastAPI, SQLite with WAL mode, and ONNX Runtime DirectML. The frontend uses vanilla JavaScript and Chart.js without runtime CDN dependencies or node build steps.
