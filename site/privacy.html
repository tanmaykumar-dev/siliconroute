Privacy Policy

SiliconRoute is designed to run entirely on your local machine. We prioritize user privacy and data sovereignty by design.

1. Local Execution Only

The SiliconRoute application executes on your local hardware. It runs a local HTTP server at 127.0.0.1:8000 and stores all benchmark measurements in a local SQLite database file. No telemetry, benchmark results, device identifiers, or user inputs are ever uploaded to any remote server or cloud service.

2. Website Privacy

This static documentation website does not use cookies, does not collect analytics, contains no tracking scripts or third-party pixels, and makes zero external network requests.

3. Contact

If you have any questions or security disclosures, please open an issue on our official repository at GitHub Issues.
