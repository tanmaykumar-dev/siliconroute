Run the local telemetry dashboard

The interactive telemetry dashboard runs locally on your workstation to profile your physical CPU, iGPU, and dGPU.

How to start the dashboard locally

Step 1: Clone the repository

git clone https://github.com/tanmaykumar-dev/siliconroute.git
cd siliconroute

Step 2: Start the application

Double-click start.bat on Windows, or run:

.\venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Once started, open http://127.0.0.1:8000/app to view live device telemetry, interactive fits, and the workload router.
