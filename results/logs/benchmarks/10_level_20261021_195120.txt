 [PHASE 5] ARCHITECTURAL ANALYSIS (Hypotheses & Physics Rationale)
===================================================================================================================
Hypothesis: For MLP models, the crossover between CPU and discrete GPU (NVIDIA RTX 5070)
follows model weight footprint relative to the 64 MB CPU cache (AMD Ryzen 9 8940HX L3 cache),
rather than FLOP count.
  - MLPs possess low arithmetic intensity (~1.0 FLOP/byte), meaning every parameter is read once
    per sample. When weights fit inside the 64 MB CPU cache, the CPU avoids DRAM latency and runs at
    on-die cache bandwidth, outperforming the dGPU which incurs PCIe dispatch latency overhead.
  - When MLP weights exceed 64 MB, CPU execution must stream from system DDR5 RAM (~50-70 GB/s),
    allowing the RTX 5070's high-bandwidth GDDR6 VRAM (~350 GB/s) to overcome bus dispatch overhead.
  - For Convolutional models with spatial kernel reuse, higher arithmetic intensity enables the GPU
    to win at significantly smaller parameter memory footprints once compute outweighs dispatch cost.
